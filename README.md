## 🚀 Featured Projects

### 📚 AaruEdu — Homework Hub

A full-stack homework management application designed to help elementary school teachers, parents, and students stay organized and connected.<br>
Inspired by my own experience as a parent, I created AaruEdu to make homework communication easier, reduce confusion around assignments, 
and help families stay on top of their children's learning.
- 📝 Assignment creation, management, and tracking

- 📎 File attachments with upload, view, download, and delete functionality

- 🔐 JWT-based authentication and role-based access control

- 👨‍👩‍👧 Separate dashboards for parents, teachers, and students

- 🧭 Role-based navigation for a personalized user experience

- 📅 Calendar functionality to view and manage assignment due dates

- 🔔 Alerts and notifications to keep users informed about assignments

- 🔗 RESTful APIs built with Spring Boot and Spring Data JPA

- 🗄️ MySQL database integration for persistent data storage

**Tech Stack:**  Java · Spring Boot · Spring Security · JWT · React · JavaScript · MySQL · Hibernate

[**View AaruEdu on GitHub →**](https://github.com/pujajathar/Homework-Hub-Full-Stack-App)
